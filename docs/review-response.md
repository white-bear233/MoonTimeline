# 本轮初审意见整改对照（2026-10-27）

基于 DeepSeek 后续工作后的 `1d3e324` / 0.1.2 继续开发。本轮仓库版本为 0.1.3；此文不代表已通过赛事复审，也不代表已发布到 Mooncakes。

| 审核意见 | 本轮落地 | 验证证据 |
|---|---|---|
| Transition 的时间范围遗漏 | 新增类型视图、完整范围、裁剪后可见范围、剪切点、左右邻居路径和时间点查询；转场本身有时长，内部转场不推进游标；首尾转场遵循上游 available_range 规则 | `conformance/oracle_test.mbt`：官方 OTIO 生成的内部、首尾、裁剪、混合帧率、零 Gap 与多层嵌套结构预期；`conformance/review_test.mbt`：范围/时长/半开查询 |
| 相邻片段约束遗漏 | 检查负数/非法 offset、相邻转场、转场超过相邻片段、同片段两端转场重叠；按前一个转场的 in_offset、后一个的 out_offset 检查素材余量 | 相邻、重叠、首尾及零 Gap、素材余量不足、变速余量测试；无效编辑拒绝且原工程不变 |
| 变速对素材坐标影响不明 | 片段 `media(t)=source_start+(t-placement_start)*time_scalar`；展示时长不除以 scalar；支持快放/慢放/倒放/定格，裁剪和拆分的起点同步变更 | 4 类效果的布局/编辑/素材边界测试；官方读写实际导出；组合上的变速仍明确拒绝计算并列入下一阶段 |
| Marker、Metadata 编辑后可能丢失 | Marker 使用宿主 source 坐标；裁剪与拆分不自动移动、删减或归零标记，范围外标记仍保留；拆分复制独立标记列表；所有宿主 Metadata、效果、媒体引用和扩展字段保留 | 深层 JSON 全量对比、修改一段标记列表不影响另一段或输入；21 个实际编辑导出经官方 OTIO 互读，输入与输出只允许预期范围/列表变化 |
| 仅承诺核心子集 | 明确以 OTIO v0.18.1 完整公开能力为目标，列出全部 schema、opentime/core/algorithms、版本迁移、内置适配器与插件机制 | [完整实现路线图](otio-roadmap.md) 与 [修订申报书](proposal.md)，每阶段有退出条件，未完成项不标成完成 |

额外修正：嵌套多层非零 source_range 的坐标起点；此前将 Metadata 中 Inf/NaN 变成 null 的行为改为明确拒绝，避免数据损失。OTIO 允许特殊数值，因此拒绝意味着兼容性尚有缺口，并非这类上游工程非法。

注意区分三个概念：**能读写保留**、**能安全计算**、**完整语义兼容**。旧版“13/13 可计算”只测布局未报错，不能证明转场、变速、嵌套坐标正确。本轮上游样例结果为可读/可写回 12/13、布局返回 11/13：`big_int.otio` 含特殊数值，明确拒绝；`nested_example.otio` 含组合变速，保留工程但拒绝计算。其余支持样例写回前后的完整检查报告一致。

仍待完成：组合变速、嵌套组合转场余量的递归验证、Marker 独立编辑与可见性查询、完整 schema/API/算法和适配器。未知媒体可用范围给出无法验证提示，不伪造素材长度；嵌套组合转场余量给出 Warning，不能据此声称素材一定可交付。已知素材越界按本库的严格质检策略报 Error；上游 OTIO 本身允许保存这种工程，导出保留接口不会因此拒绝。
